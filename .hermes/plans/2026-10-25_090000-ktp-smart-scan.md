Read `2026-10-25_090000-hc-staff-identity-roadmap.md` first — decisions X2 and X3 govern this plan, and the environment facts table records why the provider question is a gate rather than an implementation detail. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add an optional KTP smart-scan step that reads an uploaded KTP image, extracts the seven identity fields the source document names, and shows them for per-field confirmation before they reach the intake form.

**Architecture:** Three independent layers, so the undecided provider cannot block delivery. (1) A deterministic **text parser** that maps OCR output to KTP fields — pure Python, fully testable, no OCR binary needed. (2) An **adapter interface** with a local Tesseract implementation, a null implementation, and a documented extension point for a cloud provider. (3) A **confirm UI** that renders extracted values as an editable draft, never as auto-filled form state. The whole feature sits behind `HC_KTP_SCAN_ENABLED`, default off. When the flag is off or the adapter is unavailable, the intake wizard behaves exactly as it does today.

**Tech Stack:** Python `re` and `difflib` for the parser; `pytesseract` + `Pillow` for the local adapter; Django templates + one small JS file for the confirm UI. No new service is required to ship the parser and the UI.

Consequences, which this plan takes as given:

- **The parser is the deliverable that ships now.** It is deterministic, unit-testable, and useful the moment any adapter produces text.
- **The local adapter ships behind the flag.** It works on a host with the binary (Railway with `nixPkgs = ["tesseract"]`), reports itself unavailable elsewhere, and never raises.
- **No cloud OCR is implemented.** Adding one is a documented extension point plus a settings value; it requires a provider decision, a spend approval, and a data-processing consideration for sending an identity document off-premises. Those are the operator's calls, not the plan's.
- **Nothing here may become a precondition for saving an employee.** Decision X3.

## Global constraints

Every task inherits the roadmap's Global constraints. In addition:

- `HC_KTP_SCAN_ENABLED` defaults to `False`. With it `False`, no template renders a scan control; an authenticated direct POST to the registered route returns the explicit unavailable result and persists nothing.
- The adapter returns a structured result, never raises: `OcrResult(text, available, reason, engine, duration_ms)`.
- Extracted values never write to `request.POST`, to `DrafInputPegawai.draft_data`, or to any model. They render into an editable form the operator submits.
- No KTP image is retained after extraction. The upload is read into memory, processed, and discarded; the durable copy is the one the operator separately attaches in step 5 as `LampiranDrafPegawai` with `artifact_kind='KTP'`.
- Extracted text and extracted field values are never logged. `logger.info('ktp_scan engine=%s duration_ms=%s fields=%s', ...)` may record the engine, the duration, and the *count* of fields — never a value.
- UI copy is Bahasa Indonesia and literal.

```python
"""Deterministic KTP text parser.

Turns OCR output into the seven identity fields the intake wizard needs.
Pure functions: no OCR engine, no network, no database, no logging of values.
"""

import re
from dataclasses import dataclass, field
from datetime import date

NIK_RE = re.compile(r'(?<!\d)(\d{16})(?!\d)')

# OCR routinely substitutes these inside numeric fields. Repaired only in a
# span already known to be numeric, never across a whole document.
DIGIT_REPAIRS = str.maketrans({'O': '0', 'o': '0', 'l': '1', 'I': '1', 'S': '5', 'B': '8', 'Z': '2'})

BULAN = {
    'JANUARI': 1, 'FEBRUARI': 2, 'MARET': 3, 'APRIL': 4, 'MEI': 5, 'JUNI': 6,
    'JULI': 7, 'AGUSTUS': 8, 'SEPTEMBER': 9, 'OKTOBER': 10, 'NOVEMBER': 11,
    'DESEMBER': 12,
}

AGAMA_MAP = {
    'ISLAM': 'ISLAM',
    'KRISTEN KATOLIK': 'KRISTEN_KATOLIK',
    'KATOLIK': 'KRISTEN_KATOLIK',
    'KRISTEN': 'KRISTEN_PROTESTAN',
    'PROTESTAN': 'KRISTEN_PROTESTAN',
    'HINDU': 'HINDU',
    'BUDDHA': 'BUDDHA',
    'KONGHUCU': 'KONGHUCU',
}

MARITAL_MAP = {
    'BELUM KAWIN': 'BELUM_KAWIN',
    'KAWIN': 'KAWIN',
    'CERAI HIDUP': 'CERAI_HIDUP',
    'CERAI MATI': 'CERAI_MATI',
}

LABELS = {
    'nik': ('NIK', 'NlK', 'N1K'),
    'nama': ('Nama', 'Nama Lengkap'),
    'ttl': ('Tempat/Tgl Lahir', 'Tempat/Tanggal Lahir', 'Tempat, Tgl Lahir'),
    'gender': ('Jenis Kelamin', 'JenisKelamin'),
    'alamat': ('Alamat',),
    'agama': ('Agama',),
    'status': ('Status Perkawinan', 'StatusPerkawinan'),
}


@dataclass
class KtpFields:
    nik: str = ''
    nama: str = ''
    tempat_lahir: str = ''
    tanggal_lahir: date | None = None
    gender: str = ''
    agama: str = ''
    status_pernikahan: str = ''
    alamat: str = ''
    confidence: dict = field(default_factory=dict)
    raw_lines: list = field(default_factory=list)


def _digits(value):
    """Repair OCR substitutions in a span that must be numeric."""
    return (value or '').translate(DIGIT_REPAIRS)


def _clean(value):
    return re.sub(r'\s+', ' ', (value or '')).strip(' :|-–—')


def _parse_date(raw):
    """Accept 12-05-1990, 12/05/1990, 12 MEI 1990, 12-5-90."""
    text = _clean(raw).upper()
    text = text.replace('/', '-').replace('.', '-')
    numeric = re.match(r'^(\d{1,2})-(\d{1,2})-(\d{2,4})$', _digits(text))
    if numeric:
        day, month, year = (int(part) for part in numeric.groups())
        year = year + 1900 if year < 100 else year
        try:
            return date(year, month, day)
        except ValueError:
            return None
    named = re.match(r'^(\d{1,2})\s+([A-Z]+)\s+(\d{4})$', text)
    if named:
        day, month_name, year = named.groups()
        month = BULAN.get(month_name)
        if month:
            try:
                return date(int(year), month, int(day))
            except ValueError:
                return None
    return None


def nik_checks(nik):
    """Structural checks on a 16-digit NIK. No checksum exists in the format."""
    result = {'valid': False, 'province': '', 'birth_date': None,
              'gender': '', 'reason': ''}
    cleaned = _digits((nik or '').strip())
    if not re.fullmatch(r'\d{16}', cleaned):
        result['reason'] = 'NIK harus 16 digit.'
        return result
    result['province'] = cleaned[:2]
    day = int(cleaned[6:8])
    month = int(cleaned[8:10])
    year = int(cleaned[10:12])
    year = year + 1900 if year > 30 else year + 2000
    gender = 'LAKI_LAKI'
    if day > 40:
        day -= 40
        gender = 'PEREMPUAN'
    try:
        result['birth_date'] = date(year, month, day)
    except ValueError:
        result['reason'] = 'Tanggal lahir di dalam NIK tidak valid.'
        return result
    result['gender'] = gender
    result['valid'] = True
    return result


def _label_value(lines, key):
    """Find `Label : value` for any known spelling of the label."""
    candidates = LABELS[key]
    for index, line in enumerate(lines):
        stripped = line.strip()
        for label in candidates:
            if not stripped.lower().startswith(label.lower()):
                continue
            remainder = stripped[len(label):].lstrip()
            if remainder[:1] in (':', '-', '='):
                remainder = remainder[1:]
            value = _clean(remainder)
            if value:
                return value
            if index + 1 < len(lines):
                return _clean(lines[index + 1])
    return ''


def _collect_address(lines):
    """Address plus the RT/RW, Kel/Desa and Kecamatan lines that follow it."""
    parts = []
    collecting = False
    for line in lines:
        stripped = _clean(line)
        upper = stripped.upper()
        if upper.startswith('ALAMAT'):
            collecting = True
            remainder = _clean(stripped[len('ALAMAT'):].lstrip(': -'))
            if remainder:
                parts.append(remainder)
            continue
        if not collecting:
            continue
        if any(
            upper.startswith(prefix)
            for prefix in ('AGAMA', 'PEKERJAAN', 'KEWARGANEGARAAN',
                           'BERLAKU', 'STATUS', 'JENIS KELAMIN', 'NIK', 'NAMA')
        ):
            break
        if stripped:
            parts.append(stripped)
    return ', '.join(parts)


def parse_ktp_text(text):
    """Parse OCR text into KtpFields. Never raises on unrecognised input."""
    lines = [line for line in (text or '').splitlines()]
    fields = KtpFields(raw_lines=[line for line in lines if line.strip()])

    # First accept a real 16-digit sequence anywhere. OCR character repairs are
    # allowed only in the value associated with a recognised NIK label; applying
    # them to the whole document can turn an unrelated run of letters into a NIK.
    nik_match = NIK_RE.search(text or '')
    if nik_match:
        fields.nik = nik_match.group(1)
    else:
        labelled = re.sub(
            r'[\s.\-/]', '', _digits(_label_value(lines, 'nik'))
        )
        if re.fullmatch(r'\d{16}', labelled):
            fields.nik = labelled

    fields.nama = _label_value(lines, 'nama')

    ttl = _label_value(lines, 'ttl')
    if ttl:
        if ',' in ttl:
            tempat, _, tanggal = ttl.partition(',')
            fields.tempat_lahir = _clean(tempat).upper()
            fields.tanggal_lahir = _parse_date(tanggal)
        else:
            fields.tempat_lahir = _clean(ttl).upper()

    gender_raw = _label_value(lines, 'gender').upper()
    if 'PEREMPUAN' in gender_raw or 'WANITA' in gender_raw:
        fields.gender = 'PEREMPUAN'
    elif 'LAKI' in gender_raw or 'PRIA' in gender_raw:
        fields.gender = 'LAKI_LAKI'

    agama_raw = _label_value(lines, 'agama').upper()
    for token, code in AGAMA_MAP.items():
        if token in agama_raw:
            fields.agama = code
            break

    marital_raw = _label_value(lines, 'status').upper()
    for token, code in MARITAL_MAP.items():
        if token in marital_raw:
            fields.status_pernikahan = code
            break

    fields.alamat = _collect_address(lines)

    checks = nik_checks(fields.nik) if fields.nik else {'valid': False}
    fields.confidence = {
        'nik': 'high' if checks.get('valid') else 'low',
        # KTP names are printed uppercase. Lowercase OCR output usually signals
        # an unresolved l/I-style ambiguity and must remain operator-reviewed.
        'nama': (
            'high' if fields.nama and fields.nama == fields.nama.upper() else 'low'
        ),
        'tanggal_lahir': 'low',
        'tempat_lahir': 'high' if fields.tempat_lahir else 'low',
        'gender': 'high' if fields.gender else 'low',
        'agama': 'high' if fields.agama else 'low',
        'status_pernikahan': 'high' if fields.status_pernikahan else 'low',
        'alamat': 'high' if fields.alamat else 'low',
    }

    if fields.tanggal_lahir:
        embedded = checks.get('birth_date')
        if embedded and embedded == fields.tanggal_lahir:
            fields.confidence['tanggal_lahir'] = 'high'
            if fields.gender and fields.gender == checks.get('gender'):
                fields.confidence['gender'] = 'high'
            elif fields.gender and checks.get('gender'):
                fields.confidence['gender'] = 'low'
        else:
            # Two independent readings disagree: the operator must look at both.
            fields.confidence['tanggal_lahir'] = 'low'
    elif checks.get('birth_date'):
        fields.tanggal_lahir = checks['birth_date']
        fields.confidence['tanggal_lahir'] = 'low'

    if not fields.gender and checks.get('gender'):
        fields.gender = checks['gender']

    return fields
```

The design point worth stating: `confidence['tanggal_lahir']` is `'low'` unless the printed date and the date embedded in the NIK agree. Those are two independent readings of the same fact, and their agreement is the only real signal available without a checksum.

Create `sdm/services/ktp_ocr.py`:

```python
"""Pluggable OCR adapters for KTP smart scan.

Every adapter returns an OcrResult and never raises: a missing engine, an
undecodable image, or a provider outage is a normal outcome the UI must be
able to describe, not an exception that turns into a 500.
"""

import logging
import time
from dataclasses import dataclass
from io import BytesIO

from django.conf import settings

logger = logging.getLogger(__name__)

# Preprocessing bounds. A KTP is a small card; anything far larger is a phone
# photo that needs downscaling before OCR, not a bigger image.
MAX_OCR_DIMENSION = 2000
MAX_OCR_PIXELS = 20_000_000
OCR_LANGUAGES = 'ind'


@dataclass(frozen=True)
class OcrResult:
    text: str = ''
    available: bool = False
    reason: str = ''
    engine: str = ''
    duration_ms: int = 0


def _tesseract_version():
    """Return the engine version string, or None when it is not installed."""
    try:
        import pytesseract
    except ImportError:
        return None
    try:
        return str(pytesseract.get_tesseract_version())
    except Exception:
        return None


def _run_tesseract(image):
    import pytesseract

    if OCR_LANGUAGES:
        return pytesseract.image_to_string(image, lang=OCR_LANGUAGES)
    return pytesseract.image_to_string(image)


class NullAdapter:
    """Used when the feature is off or the configured engine is unknown."""

    name = 'null'

    def extract(self, image_bytes):
        return OcrResult(
            available=False,
            reason=(
                'Pemindaian KTP belum diaktifkan pada instalasi ini. '
                'Isi data identitas secara manual.'
            ),
            engine=self.name,
        )


class TesseractAdapter:
    """Local Tesseract. Free and offline; needs the system binary installed."""

    name = 'tesseract'

    def extract(self, image_bytes):
        started = time.monotonic()

        def elapsed():
            return int((time.monotonic() - started) * 1000)

        if _tesseract_version() is None:
            return OcrResult(
                available=False,
                reason=(
                    'Mesin Tesseract tidak tersedia pada server ini. '
                    'Isi data identitas secara manual.'
                ),
                engine=self.name,
                duration_ms=elapsed(),
            )
        if not isinstance(image_bytes, (bytes, bytearray)) or not image_bytes:
            return OcrResult(
                available=False,
                reason='Berkas gambar kosong atau tidak dapat dibaca.',
                engine=self.name,
                duration_ms=elapsed(),
            )
        limit = getattr(settings, 'HC_KTP_OCR_MAX_BYTES', 10_485_760)
        if len(image_bytes) > limit:
            return OcrResult(
                available=False,
                reason='Berkas gambar melebihi batas ukuran.',
                engine=self.name,
                duration_ms=elapsed(),
            )

        try:
            from PIL import Image, ImageOps, UnidentifiedImageError
        except ImportError:
            return OcrResult(
                available=False,
                reason='Pustaka pengolah gambar tidak tersedia pada server ini.',
                engine=self.name,
                duration_ms=elapsed(),
            )

        try:
            with Image.open(BytesIO(bytes(image_bytes))) as source:
                if source.width * source.height > MAX_OCR_PIXELS:
                    return OcrResult(
                        available=False,
                        reason='Resolusi gambar melebihi batas pemindaian.',
                        engine=self.name,
                        duration_ms=elapsed(),
                    )
                image = ImageOps.exif_transpose(source).convert('L')
                if max(image.size) > MAX_OCR_DIMENSION:
                    image.thumbnail(
                        (MAX_OCR_DIMENSION, MAX_OCR_DIMENSION), Image.LANCZOS
                    )
                image = ImageOps.autocontrast(image)
                text = _run_tesseract(image)
        except (UnidentifiedImageError, OSError, ValueError):
            return OcrResult(
                available=False,
                reason='Berkas bukan gambar yang dapat dibaca.',
                engine=self.name,
                duration_ms=elapsed(),
            )
        except Exception:
            # A Tesseract runtime failure must not surface as a 500.
            return OcrResult(
                available=False,
                reason='Pemindaian KTP gagal diproses. Isi data secara manual.',
                engine=self.name,
                duration_ms=elapsed(),
            )

        text = (text or '').strip()
        if not text:
            return OcrResult(
                available=False,
                reason='Tidak ada teks yang terbaca dari gambar. Coba foto yang lebih jelas.',
                engine=self.name,
                duration_ms=elapsed(),
            )
        return OcrResult(
            text=text, available=True, engine=self.name, duration_ms=elapsed()
        )


ADAPTERS = {
    'tesseract': TesseractAdapter,
    # A cloud adapter registers here once a provider is chosen. It must accept
    # image bytes, return OcrResult, and never raise. See the provider gate in
    # the plan: sending an identity document off-premises is an operator
    # decision, not a default.
}


def get_adapter():
    if not getattr(settings, 'HC_KTP_SCAN_ENABLED', False):
        return NullAdapter()
    engine = (getattr(settings, 'HC_KTP_OCR_ENGINE', '') or '').lower()
    adapter_class = ADAPTERS.get(engine)
    if adapter_class is None:
        logger.warning('Unknown HC_KTP_OCR_ENGINE configured; KTP scan disabled.')
        return NullAdapter()
    return adapter_class()
```

```python
"""KTP smart-scan endpoint. Extracts nothing durable; returns fields for review."""

import logging

from django.conf import settings
from django.contrib.auth.decorators import login_required
from django.http import JsonResponse
from django.views.decorators.http import require_POST

from akreditasi.security_utils import rate_limit
from sdm.akses import require_hc_capability
from sdm.services.ktp_ocr import get_adapter
from sdm.services.ktp_parser import parse_ktp_text

logger = logging.getLogger(__name__)

@login_required
@require_POST
@rate_limit(max_calls=10, window=60, scope='ktp-scan')
def pegawai_ktp_scan(request):
    require_hc_capability(request.user, 'can_view_hc')
    require_hc_capability(request.user, 'can_manage_hc_employees')

    upload = request.FILES.get('ktp_image')
    if upload is None:
        return JsonResponse(
            {'ok': False, 'available': False,
             'reason': 'Berkas KTP tidak dikirim.', 'fields': {}, 'confidence': {}},
            status=400,
        )
    max_bytes = getattr(settings, 'HC_KTP_OCR_MAX_BYTES', 10_485_760)
    if type(max_bytes) is not int or max_bytes <= 0:
        max_bytes = 10_485_760
    if upload.size > max_bytes:
        return JsonResponse(
            {'ok': False, 'available': False,
             'reason': 'Berkas melebihi batas ukuran pemindaian.', 'fields': {}, 'confidence': {}},
            status=400,
        )

    data = upload.read(max_bytes + 1)
    if not isinstance(data, bytes) or not data or len(data) > max_bytes:
        return JsonResponse(
            {'ok': False, 'available': False,
             'reason': 'Berkas kosong atau melebihi batas ukuran.',
             'fields': {}, 'confidence': {}},
            status=400,
        )
    if not (data.startswith(b'\xff\xd8\xff') or data.startswith(b'\x89PNG\r\n\x1a\n')):
        return JsonResponse(
            {'ok': False, 'available': False,
             'reason': 'Berkas harus berupa JPG atau PNG yang valid.',
             'fields': {}, 'confidence': {}},
            status=400,
        )
    result = get_adapter().extract(data)

    # Only the engine, the duration and the number of recognised fields are
    # logged. Never the extracted text or any field value.
    logger.info(
        'ktp_scan engine=%s available=%s duration_ms=%s',
        result.engine, result.available, result.duration_ms,
    )

    if not result.available:
        return JsonResponse({
            'ok': False, 'available': False, 'reason': result.reason,
            'fields': {}, 'confidence': {},
        })

    fields = parse_ktp_text(result.text)
    recognised = sum(
        1 for value in (
            fields.nik, fields.nama, fields.tempat_lahir, fields.tanggal_lahir,
            fields.gender, fields.agama, fields.status_pernikahan, fields.alamat,
        ) if value
    )
    logger.info('ktp_scan fields_recognised=%s', recognised)

    return JsonResponse({
        'ok': True,
        'available': True,
        'reason': '',
        'fields': {
            'nik': fields.nik,
            'nama': fields.nama,
            'tempat_lahir': fields.tempat_lahir,
            'tanggal_lahir': (
                fields.tanggal_lahir.isoformat() if fields.tanggal_lahir else ''
            ),
            'gender': fields.gender,
            'agama': fields.agama,
            'status_pernikahan': fields.status_pernikahan,
            'alamat': fields.alamat,
        },
        'confidence': fields.confidence,
    })
```

- [ ] **Step 5: Create the confirm script**

Create `static/js/hc-ktp-scan.js`:

```javascript
/**
 * KTP smart scan — review-before-fill.
 *
 * Extracted values are rendered as editable, monospaced text in a review table.
 * Nothing is copied into the intake form until the operator presses
 * "Terapkan ke formulir", and even then only non-empty values are applied.
 */
(function () {
    'use strict';

    var root = document.querySelector('[data-hc-ktp-scan]');
    if (!root) return;

    var fileInput = root.querySelector('[data-hc-ktp-file]');
    var status = root.querySelector('[data-hc-ktp-status]');
    var resultBox = root.querySelector('[data-hc-ktp-result]');
    var rowsBody = root.querySelector('[data-hc-ktp-rows]');
    var actions = root.querySelector('[data-hc-ktp-actions]');

    var FIELDS = [
        ['nik', 'NIK'],
        ['nama', 'Nama Lengkap'],
        ['tempat_lahir', 'Tempat Lahir'],
        ['tanggal_lahir', 'Tanggal Lahir'],
        ['gender', 'Jenis Kelamin'],
        ['agama', 'Agama'],
        ['status_pernikahan', 'Status Pernikahan'],
        ['alamat', 'Alamat KTP']
    ];

    // KTP field -> current IntakeStep1Form element id. The KTP has one full
    // name while the form has first/last name; put the reviewed full name in
    // nama_depan rather than inventing a split that could corrupt the name.
    var TARGETS = {
        nik: 'id_nik',
        nama: 'id_nama_depan',
        tempat_lahir: 'id_tempat_lahir',
        tanggal_lahir: 'id_tanggal_lahir',
        gender: 'id_gender',
        agama: 'id_agama',
        status_pernikahan: 'id_status_pernikahan',
        alamat: 'id_alamat_ktp'
    };

    var CHOICES = {
        gender: [
            ['', '—'], ['LAKI_LAKI', 'Laki-laki'], ['PEREMPUAN', 'Perempuan']
        ],
        agama: [
            ['', '—'], ['ISLAM', 'Islam'],
            ['KRISTEN_PROTESTAN', 'Kristen Protestan'],
            ['KRISTEN_KATOLIK', 'Kristen Katolik'], ['HINDU', 'Hindu'],
            ['BUDDHA', 'Buddha'], ['KONGHUCU', 'Konghucu'],
            ['LAINNYA', 'Lainnya']
        ],
        status_pernikahan: [
            ['', '—'], ['BELUM_KAWIN', 'Belum Kawin'], ['KAWIN', 'Kawin'],
            ['CERAI_HIDUP', 'Cerai Hidup'], ['CERAI_MATI', 'Cerai Mati']
        ]
    };

    function csrfToken() {
        var input = document.querySelector('[name=csrfmiddlewaretoken]');
        if (input) return input.value;
        var cookie = document.cookie.split('; ').find(function (row) {
            return row.indexOf('csrftoken=') === 0;
        });
        return cookie ? cookie.split('=')[1] : '';
    }

    function setStatus(text) {
        if (status) status.textContent = text || '';
    }

    function rowFor(key, label, value, confidence) {
        var tr = document.createElement('tr');
        var th = document.createElement('th');
        th.scope = 'row';
        th.className = 'fw-normal small';
        th.textContent = label;

        var td = document.createElement('td');
        var input;
        if (CHOICES[key]) {
            input = document.createElement('select');
            CHOICES[key].forEach(function (choice) {
                var option = document.createElement('option');
                option.value = choice[0];
                option.textContent = choice[1];
                input.appendChild(option);
            });
        } else {
            input = document.createElement('input');
            input.type = 'text';
        }
        input.className = CHOICES[key]
            ? 'form-select form-select-sm font-monospace'
            : 'form-control form-control-sm font-monospace';
        input.value = value || '';
        input.dataset.hcKtpKey = key;
        td.appendChild(input);

        var tdConf = document.createElement('td');
        if (confidence === 'low') {
            var badge = document.createElement('span');
            badge.className = 'badge text-bg-danger';
            badge.textContent = 'Perlu diperiksa';
            tdConf.appendChild(badge);
        } else if (value) {
            var ok = document.createElement('span');
            ok.className = 'badge text-bg-success';
            ok.textContent = 'Terbaca';
            tdConf.appendChild(ok);
        } else {
            tdConf.textContent = '—';
        }

        tr.appendChild(th);
        tr.appendChild(td);
        tr.appendChild(tdConf);
        return tr;
    }

    function render(payload) {
        rowsBody.textContent = '';
        actions.textContent = '';
        FIELDS.forEach(function (spec) {
            var key = spec[0], label = spec[1];
            rowsBody.appendChild(
                rowFor(key, label, payload.fields[key], payload.confidence[key])
            );
        });

        var apply = document.createElement('button');
        apply.type = 'button';
        apply.className = 'btn btn-outline-primary btn-sm mt-2';
        apply.textContent = 'Terapkan ke formulir';
        apply.addEventListener('click', applyToForm);
        actions.appendChild(apply);

        resultBox.classList.remove('d-none');
    }

    function applyToForm() {
        var applied = 0;
        rowsBody.querySelectorAll('[data-hc-ktp-key]').forEach(function (input) {
            var key = input.dataset.hcKtpKey;
            var target = document.getElementById(TARGETS[key]);
            if (!target || !input.value) return;
            // Never overwrite a value the operator already typed.
            if (target.value && target.value !== input.value) return;
            target.value = input.value;
            applied += 1;
        });
        setStatus(applied + ' kolom diterapkan. Periksa kembali sebelum menyimpan.');
    }

    if (fileInput) {
        fileInput.addEventListener('change', function () {
            var file = fileInput.files && fileInput.files[0];
            if (!file) return;
            setStatus('Memindai…');
            resultBox.classList.add('d-none');

            var body = new FormData();
            body.append('ktp_image', file);

            fetch(root.dataset.hcKtpUrl, {
                method: 'POST',
                headers: {
                    'X-CSRFToken': csrfToken(),
                    'X-Requested-With': 'XMLHttpRequest'
                },
                body: body,
                credentials: 'same-origin'
            })
                .then(function (response) { return response.json(); })
                .then(function (payload) {
                    if (!payload.available) {
                        setStatus(
                            payload.reason || payload.error ||
                            'Pemindaian tidak tersedia.'
                        );
                        return;
                    }
                    setStatus('Hasil pindai siap diperiksa.');
                    render(payload);
                })
                .catch(function () {
                    setStatus('Pemindaian gagal. Isi data identitas secara manual.');
                });
        });
    }
})();
```

Two behaviours worth defending: `applyToForm` refuses to overwrite an existing non-empty value, so a scan cannot destroy typed input; and the whole panel is a review table rather than a silent fill, which is the only way the operator can catch a digit misread.

## Definition of done

With the flag off, the intake wizard renders no control or script and a direct
authenticated scan POST returns an unavailable result without persisting data.
With the flag on and an engine present, an operator uploads a KTP photo, sees
each of the eight extracted values in a monospaced review row with a confidence
badge, edits anything wrong, and applies only what they have read — with no
automatic fill and no overwrite of typed input. With the flag on and no engine,
the panel reports in Indonesian that the engine is unavailable and the operator
types the identity manually. The parser's behaviour is pinned by unit tests that
need no OCR binary, including the `+40` female-NIK day offset and the
dual-reading date and gender confidence rules.
